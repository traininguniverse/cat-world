# 🐱 Kotusia Strona 🐱

- 🎨 **Nowoczesny Design** - Gradientowe tło i piękne animacje

## 🎮 Kotusia Gra

### Jak grać:
- **Sterowanie:** Strzałki lub WASD
- **Cel:** Zbieraj smakołyki i unikaj przeszkód
- **Power-upy:** Zbieraj specjalne przedmioty
- **Poziomy:** Gra staje się trudniejsza z każdym poziomem

### Funkcje gry:
- 🐟 **Smakołyki** - Zbieraj ryby, mięso i inne przysmaki
- 💥 **Przeszkody** - Unikaj bomb, ognia i piorunów
- 🔋 **Power-upy:**
  - 🥛 Mleko - +1 życie
  - ⭐ Gwiazda - Tarcza (5 sekund)
  - 💎 Diament - +50 punktów
- 🎵 **Efekty dźwiękowe** - Dźwięki przy zbieraniu i kolizjach
- ✨ **Animacje** - Piękne efekty cząsteczkowe

## 🚀 Jak uruchomić

1. **Otwórz plik `index.html` w przeglądarce**
   - Kliknij dwukrotnie na plik `index.html`
   - Lub przeciągnij plik do okna przeglądarki

2. **Lub uruchom lokalny serwer:**
   ```bash
   # Jeśli masz Python 3
   python3 -m http.server 8000
   
   # Jeśli masz Node.js
   npx serve .
   
   # Jeśli masz PHP
   php -S localhost:8000
   ```

3. **Otwórz w przeglądarce:**
   - `http://localhost:8000` - Główna strona
   - `http://localhost:8000/game.html` - Gra

## 🎮 Jak używać

### Główna strona:
- **Kliknij przycisk "Kliknij mnie! 🎉"** - zobaczysz konfetti i modal!
- **Kliknij kotki w galerii** - każdy ma swoją wiadomość!
- **Przewiń stronę** - zobacz efekty parallax
- **Spróbuj kodu Konami** - ↑↑↓↓←→←→BA (klawisze strzałek + B + A)
- **Kliknij "🎮 Zagraj teraz!"** - przejdź do gry!

### Gra:
- **Strzałki/WASD** - Steruj kotkiem
- **SPACJA** - Pauza
- **Zbieraj smakołyki** - Zdobądź punkty
- **Unikaj przeszkód** - Strać życie przy kolizji
- **Power-upy** - Zbieraj specjalne przedmioty
- **Przejdź poziomy** - Graj dalej!

## 🎮 Mechanika gry

### System punktów:
- 🐟 Ryba: +10 punktów
- 🍖 Mięso: +10 punktów
- 🥩 Stek: +10 punktów
- 🍗 Kurczak: +10 punktów
- 💎 Diament: +50 punktów

### System żyć:
- Start: 3 życia
- 🥛 Mleko: +1 życie
- 💥 Kolizja z przeszkodą: -1 życie

### Poziomy:
- Każdy poziom wymaga 100 punktów
- Trudność rośnie z każdym poziomem
- Więcej przeszkód, szybsze obiekty
